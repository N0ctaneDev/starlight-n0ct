# Contributing

Thanks for helping improve @n0ctanedev/starlight-n0ct.

## Local setup

```sh
npm install
npm run check
npm run docs:dev
```

## Pull requests

- Keep changes focused and explain the user-facing impact.
- Add or update tests for configuration behavior.
- Update the demo documentation when changing public options.
- Respect keyboard accessibility and `prefers-reduced-motion`.
- Do not copy source code from other themes; use references for design direction and implement original components.

## Commit guidance

Use concise imperative commit messages. Include screenshots for visual changes where practical.

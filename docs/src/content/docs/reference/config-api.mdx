## Editor IntelliSense

N0ctane exports the N0ctConfig TypeScript interface. Add a JSDoc @satisfies annotation to your JavaScript config to enable property suggestions and diagnostics:

~~~js
// @ts-check

/** @satisfies {import('@n0ctanedev/starlight-n0ct').N0ctConfig} */
const config = {
  title: 'My Documentation',
  sidebar: {
    topicDisplay: 'dropdown',
  },
};

export default config;
~~~

## Root properties

| Property | Type | Description |
|---|---|---|
| title | string | Required Starlight site title |
| favicon | string | Global favicon path relative to `public/`; theme-specific overrides are optional |
| description | string | Site description |
| sidebar.topics | N0ctSidebarTopic[] | Simplified sidebar declarations |
| sidebar.topicDisplay | collapsible, list, or dropdown | Native sidebar, topic list, or dropdown |
| sidebar.topicOptions | object | Route exclusions and route-to-topic mappings |
| sidebar.extra | N0ctNativeSidebarItem[] | Additional native Starlight entries |
| versioning | false or N0ctVersioningConfig | Native Starlight Versions options |
| integrations | object | Bundled plugin options or false to disable |
| footer | object | Footer text, links, and icons |
| icons | object | Iconify collection and icon directory |
| theme | N0ctThemeConfig | Palette, code colors, width, and glow |
| `starlight` | `Partial<StarlightUserConfig>` | Advanced Starlight escape hatch |

## Theme configuration

The theme.colors.dark and theme.colors.light objects each accept:
- palette — primary, secondary, accent, surface, text, highlight, and background colors.
- codePalette — independent syntax colors for code blocks.
- semantic — success, warning, danger, and info colors.
- overrides — role-level surface, text, border, interaction, highlight, and editor refinements.

See the [theme reference](/reference/theme/) for the complete schema and mode-qualified token list.

## Versioning

N0ctane forwards the native starlight-versions configuration:

~~~js
versioning: {
  versions: [
    { slug: '0.1.4', label: 'v0.1.4', redirect: 'same-page' },
  ],
  current: {
    label: 'v0.2.0',
    redirect: 'same-page',
  },
  exclude: ['blog/**'],
},
~~~

The content configuration must register docsVersionsLoader() from starlight-versions/loader in a versions collection. The demo and generated starter include that collection. When a configured archive is missing, the plugin creates it from current docs during the next development server start or build. Add one new version at a time.

## Native escape hatch

starlight is merged after N0ctane defaults. Use it for integrations, component overrides, or any Starlight option that does not have a simplified N0ctane setting. Advanced sidebar, components, customCss, and plugins intentionally override theme defaults.

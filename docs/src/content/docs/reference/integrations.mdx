N0ctane wraps the following Starlight plugin packages and passes their native options through unchanged. Documentation versioning is also provided by `starlight-versions` through the root `versioning` option.

| Config key | Documentation |
|---|---|
| `announcement` | [starlight-announcement](https://github.com/frostybee/starlight-announcement) |
| `kbd` | [starlight-kbd](https://github.com/HiDeoo/starlight-kbd) |
| `llmsTxt` | [starlight-llms-txt](https://github.com/delucis/starlight-llms-txt) |
| `scrollToTop` | [starlight-scroll-to-top](https://github.com/frostybee/starlight-scroll-to-top) |
| `llmActions` | [starlight-llm-actions](https://holdenhewett.github.io/starlight-llm-actions/) |
| `sidebarSwipe` | [starlight-sidebar-swipe](https://github.com/trueberryless-org/starlight-sidebar-swipe) |
| `linksValidator` | [starlight-links-validator](https://github.com/HiDeoo/starlight-links-validator) |
| `blog` | [starlight-blog](https://github.com/HiDeoo/starlight-blog) |
| `imageZoom` | [starlight-image-zoom](https://github.com/HiDeoo/starlight-image-zoom) |
| `versioning` | [starlight-versions](https://starlight-versions.vercel.app/) |

Disable any unused plugin with `false`. If an integration requires extra content directories, frontmatter fields or build configuration, follow its upstream installation guide.


### LLM index ownership

By default, `llmsTxt` is enabled and `llmActions.llmsTxt` is disabled. To let LLM Actions generate `/llms.txt` and `/llms-full.txt`, set `llmsTxt: false`. Do not enable both generators at the same time; N0ctane throws a configuration error instead of allowing duplicate routes.

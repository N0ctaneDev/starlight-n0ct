Each integration is bundled as a dependency and registered as a Starlight plugin. N0ctane forwards the native option object unless it must supply a default or compose a component to prevent a known conflict.

| Config key | Package | Responsibility |
|---|---|---|
| basePath | starlight-base-path | Prefix base paths on links |
| announcement | starlight-announcement | Announcement messages |
| kbd | starlight-kbd | Keyboard shortcuts and keycaps |
| llmsTxt | starlight-llms-txt | LLM-friendly Markdown indexes |
| scrollToTop | starlight-scroll-to-top | Scroll-to-top control |
| llmActions | starlight-llm-actions | Page action dropdown |
| sidebarSwipe | starlight-sidebar-swipe | Mobile sidebar gestures |
| linksValidator | starlight-links-validator | Internal link validation |
| blog | starlight-blog | Blog routes and metadata |
| imageZoom | starlight-image-zoom | Image zoom viewer |

Set a key to false to disable it. An empty object enables upstream defaults. Use an options object for package-specific configuration.

## Defaults supplied by N0ctane

- kbd uses macOS, Windows, and Linux keyboard presets when types are omitted.
- The global keyboard picker is not shown unless kbd.globalPicker is explicitly true.
- llmsTxt owns the index routes by default. Set llmsTxt: false to let llmActions own them.
- Blog and versioning route/component interactions are composed so their public components can both appear.
- Blog route patterns should be excluded from versioning if posts need stable URLs.

For actual option schemas, see each upstream project's documentation from the [integrations guide](/guides/integrations/).

## Typography

N0ctane keeps its existing font pairing:

- **Space Grotesk Variable** for interface and body text.
- **Space Mono** for code and monospaced content.

The fonts are bundled as package dependencies. Tailwind's `font-sans` and `font-mono` utilities use this same pairing.

## Palette

Dark and light modes have independently tuned surfaces and contrast values. The brand gradient remains pink → purple → blue → cyan in both modes.

| Token | Dark | Light |
|---|---|---|
| Pink 500 | `#F25CFF` | `#C92FCF` |
| Cyan 500 | `#00E5FF` | `#00AFC2` |
| Purple 500 | `#8C42FF` | `#7540CE` |
| Blue 500 | `#2A85FF` | `#286DCE` |
| Base background | `#0B0D17` | `#F8F7FC` |
| Surface | `#131626` | `#FFFFFF` |
| Elevated surface | `#1D2135` | `#F1EEF8` |
| Border | `#282C42` | `#DED9E9` |
| Primary text | `#E6EAF8` | `#191629` |
| Secondary text | `#C1C8E3` | `#48445E` |
| Muted text | `#7B88B8` | `#716B89` |

Semantic colors are success `#06D6A0`, warning `#FFD166`, error `#FF4D6D`, and info `#FF9F1C` in dark mode. Light mode uses darker variants for readable contrast.

The theme exposes matching Tailwind colors such as `bg-noct-bg-surface`, `text-noct-text-primary`, `text-noct-pink-500`, and `border-noct-cyan-500/40`.

## Layout

The reference layout starts with a `52rem` reading column, an `18rem` sidebar, and a `3.25rem` navbar. Use the existing `theme.contentWidth` and `theme.sidebarWidth` options to adjust the content and sidebar widths.

## Code blocks

Expressive Code keeps the current N0ctane dark/light syntax themes. Frames use a matching title bar and copy control. Shell-language fences add a terminal title strip; synchronized `:::code-tabs` persist the selected language; diff fences show deleted lines in red and inserted lines in green. The inline `[!code --]` and `[!code ++]` markers use the same deleted/inserted row styles.

## Motion and contrast

Ambient background color is deliberately subtle. Glow is reserved for selected navigation and interactive states. Transitions respect `prefers-reduced-motion: reduce`.

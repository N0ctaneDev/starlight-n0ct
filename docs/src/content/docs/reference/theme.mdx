## Typography

The theme uses **Space Grotesk Variable** for interface and body text and **Space Mono** for code.

## Color system

The theme is role-based rather than hue-named. It derives complete shade ramps from three brand seeds and maps them to surfaces, text, borders, interaction states, highlights and semantic statuses.

| Role | Purpose |
|---|---|
| primary | Main brand identity and monochrome gradient |
| secondary | Supporting brand color |
| accent | Links, focus, active controls and interactive highlights |
| base | Main page background |
| surface | Cards, panels and content surfaces |
| text.primary | Main readable text |
| text.secondary | Body text |
| text.muted | Supporting and metadata text |
| highlight | Selected or emphasized content |
| success, warning, danger, info | Semantic status colors |

Dark and light modes are configured independently. Defaults are purple-dark and blue-light, with blue/purple accents. Each mode accepts four core palette colors (primary, accent, surface, text) plus optional secondary, highlight, highlightText, and background.

## Configuration

~~~js
theme: {
  colors: {
    dark: {
      palette: {
        primary: '#7650C8',
        accent: '#3478D4',
        surface: '#151525',
        text: '#E9EAF5',
      },
    },
    light: {
      palette: {
        primary: '#286DCE',
        accent: '#7540CE',
        surface: '#FFFFFF',
        text: '#191629',
      },
    },
  },
}
~~~

Semantic statuses can be overridden independently in each mode:

~~~js
theme: {
  colors: {
    dark: {
      semantic: {
        success: { foreground: '#48C99A' },
        warning: { foreground: '#E8B95B' },
        danger: { foreground: '#EC7189' },
        info: { foreground: '#70BCEB' },
      },
    },
  },
}
~~~

For granular control, use overrides under either mode to adjust brand roles, surfaces, text, borders, interaction states, highlights and code-block details. Unset values are derived from the palette.

The generated shade ramps are available as Tailwind classes such as bg-n0ct-primary-500, text-n0ct-text-primary, and border-n0ct-border.

## Layout

The defaults use a 55rem reading width, a 17rem sidebar and a 3.25rem native Starlight header. Override theme.contentWidth and theme.sidebarWidth to change the layout.

## Code blocks

Standard fenced Markdown code blocks are supported, with :::code-tabs for tabbed variants. The theme does not provide a custom Code component. Code frames use one restrained border, no decorative macOS dots, and a consistently placed copy control. Diff additions and deletions use separate semantic green/red states.

## Background and accessibility

The ambient gradient is fixed to the viewport rather than scrolling with the document. Glow strength is configurable as subtle, balanced, or strong. Focus states remain visible and animations respect prefers-reduced-motion.

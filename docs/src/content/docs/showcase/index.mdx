## Color tokens

The active aliases (for example, --n0ct-base and --n0ct-surface) follow the selected mode. Mode-qualified tokens remain fixed and can be used when a component needs to reference a specific palette:

~~~css
.card {
  background: var(--n0ct-dark-surface);
  color: var(--n0ct-light-text-primary);
}
~~~

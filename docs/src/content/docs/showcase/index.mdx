## Theme and appearance

Switch between named palettes and Dark/Light in the site header. Then visit the [theme playground](/reference/theme/#live-theme-playground) to edit the palette and inspect the preview.

## Enabled integrations

The demo enables Blog, LLM page actions, llms.txt generation, image zoom, keyboard hints, swipe navigation, link validation, announcements, and scroll-to-top. Documentation versioning is enabled with v1.0.0 current and v0.2.0 archived.

## v1.0.0 — First stable release

- Rebuilt the documentation around focused guides, reference pages, and a complete component library.
- Added a theme playground with a structured editor, live interface preview, reset, copy, and JSON download.
- Added keyboard-driven project and integration selectors to the installer.
- Added the Blog + Documentation template alongside the documentation starter.
- Added themed favicons, palette-specific brand gradients, and a refreshed homepage and README.
- Composed LLM Page Actions with Starlight Versions so page actions and archived-version notices coexist.

## Previous releases

- v0.2.0 — Role-based color tokens, independent syntax palettes, improved code frames, and a richer demo.
- v0.1.4 and earlier — Package setup, compatibility improvements, sidebar work, and the original theme foundations.

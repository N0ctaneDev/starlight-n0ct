A documentation theme is more than a background and a font. It should make real content easier to scan, explain, and navigate.

The N0ctane component set keeps native Starlight semantics and adds callouts, badges, cards, file trees, keyboard hints, and step groups. Standard Expressive Code fences cover commands and snippets without a separate command component.

The bundled plugins add capabilities around the content: blog posts, version history, image zoom, keyboard hints, mobile sidebar gestures, LLM-friendly output, scroll-to-top, and link checking.

The [showcase](/showcase/) page puts these pieces together in one place. Use it as a reference when building your own documentation site.

N0ctane 0.2.0 is a design-system update for Astro Starlight. It keeps the small configuration surface while making the theme itself more deliberate.

The visual system now exposes mode-qualified tokens such as --n0ct-dark-base and --n0ct-light-surface. Components can reference either a stable palette or the active theme without duplicating the color calculations.

Code blocks receive their own syntax palette for dark and light modes. This means code colors can be tuned for a real editor canvas instead of borrowing colors intended for page headings, links, and surfaces.

The release also improves badges and heading accents, removes the separate Command block in favor of standard fenced code, and tidies up Expressive Code frames.

The demo now includes a blog, a version archive, a showcase page, and the bundled Starlight integrations. Browse the [showcase](/showcase/) for the working components and the [theme reference](/reference/theme/) for the new token API.

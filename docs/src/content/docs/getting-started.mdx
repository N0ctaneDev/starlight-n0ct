title: Getting started

Starlight-N0ct is an Astro Starlight theme, component kit, and project installer. Start with a generated project or add it to an existing Starlight site.

## Recommended: create a project

~~~sh
npx @n0ctanedev/starlight-n0ct init my-docs
~~~

The installer asks for the site title, description, public URL, deployment base path, and sidebar style. It then presents two keyboard-driven selectors.

- Choose **Documentation starter** for a focused docs site.
- Choose **Blog + documentation** for docs with a configured blog, author profile, and sample posts.
- Toggle optional integrations with Space and confirm with Enter.

The selector also supports arrow-key navigation, select-all, and clear-all. The installer detects npm, pnpm, yarn, or bun, and you can override the choice.

~~~sh
# Blog template without prompts
npx @n0ctanedev/starlight-n0ct init my-publication --template blog --yes

# Scaffold files without installing dependencies
npx @n0ctanedev/starlight-n0ct init my-docs --no-install

# Use pnpm
npx @n0ctanedev/starlight-n0ct init my-docs --pm pnpm
~~~

## Install in an existing project

~~~sh
npm install @n0ctanedev/starlight-n0ct @iconify-json/lucide
~~~

Create n0ct.config.mjs:

~~~js
// @ts-check

/** @satisfies {import('@n0ctanedev/starlight-n0ct').N0ctConfig} */
const config = {
  title: 'My project docs',
  description: 'Documentation for my project.',
  favicon: '/favicon.svg',
  sidebar: {
    topicDisplay: 'collapsible',
    topics: ['guides', 'reference'],
  },
  integrations: {
    blog: false,
    llmsTxt: {},
    scrollToTop: {},
  },
};

export default config;
~~~

Configure the public URL and optional deployment subpath in `astro.config.mjs`. These are Astro settings, not N0ctane settings. For a site deployed at `https://example.com/docs`, use `site: 'https://example.com'` and `base: '/docs'`. Astro's `base` is also used by `DocCard` to prefix root-relative internal links.

Configure Astro in astro.config.mjs:

~~~js
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import n0ctConfig from './n0ct.config.mjs';
import { n0ctane } from '@n0ctanedev/starlight-n0ct';

export default defineConfig({
  site: 'https://example.com',
  base: '/', // use '/docs' when deploying below a subpath
  integrations: [starlight(n0ctane(n0ctConfig))],
});
~~~

## Configure the content collection

A basic docs-only site needs Starlight's docs and i18n collections:

~~~ts
import { defineCollection } from 'astro:content';
import { docsLoader, i18nLoader } from '@astrojs/starlight/loaders';
import { docsSchema, i18nSchema } from '@astrojs/starlight/schema';

export const collections = {
  docs: defineCollection({ loader: docsLoader(), schema: docsSchema() }),
  i18n: defineCollection({ loader: i18nLoader(), schema: i18nSchema() }),
};
~~~

If you enable list/dropdown sidebar topics, extend the docs schema with topicSchema. If you enable Blog, merge blogSchema too. If you enable documentation versioning, register docsVersionsLoader() in a versions collection. The generated templates include the corresponding schema and loader setup.

## Run it

~~~sh
npm run dev
~~~

Then open the local URL printed by Astro. Build the static site with:

~~~sh
npm run build
~~~

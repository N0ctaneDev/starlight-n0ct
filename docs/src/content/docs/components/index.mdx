## Steps

<Steps>
  1. Install the dependencies:

     ~~~sh
     npm install
     ~~~

  2. Start the development server:

     ~~~sh
     npm run dev
     ~~~

  3. Build the production site:

     ~~~sh
     npm run build
     ~~~
</Steps>

Use <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> to open the command palette. The starlight-kbd integration selects the right keyboard convention for macOS, Windows, and Linux.

## Diff highlighting

The diff language marks removed rows in red and added rows in green.

~~~diff title="theme config"
- glow: 'subtle'
+ glow: 'balanced'
~~~

## Focus and line highlighting

Use Expressive Code attributes to focus a small range of lines without changing the code itself.

~~~ts title="src/config.ts" {2-3}
export default {
  theme: {
    glow: 'balanced',
    contentWidth: '58rem',
  },
};
~~~

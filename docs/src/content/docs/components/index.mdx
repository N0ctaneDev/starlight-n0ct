N0ctane keeps native Starlight semantics and adds a small set of reusable components. The semantic palette adapts by mode: purple-led in dark mode and blue-led in light mode, with independent role overrides.

## Diff highlighting

The `diff` fence language marks removed rows in red and added rows in green. Changed words are highlighted when a removed line is paired with its replacement.

```diff lang="ts" title="src/config.ts"
export default {
  title: 'N0ctOS',
- theme: { glow: 'subtle' },
+ theme: { glow: 'balanced' },
};
```

## Inline code markers

Add `[!code --]` or `[!code ++]` to a language comment to mark a removed or added line. The marker is rendered as a red or green row rather than shown as source text.

```ts title="version.ts"
const currentVersion = '0.1.3';
// [!code --]
const nextVersion = '0.1.3';
// [!code ++]
const nextVersion = '0.1.4';
```

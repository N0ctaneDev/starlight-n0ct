## Components are composable

Use the components where they help readers, not as decoration on every page. Cards work well for navigation, grids group related destinations, callouts highlight information that changes how a reader should proceed, and steps are best for ordered procedures.

## Import paths

All custom documentation components are exported from the package:

~~~mdx
import Callout from '@n0ctanedev/starlight-n0ct/components/docs/Callout.astro';
import DocCard from '@n0ctanedev/starlight-n0ct/components/docs/DocCard.astro';
import DocGrid from '@n0ctanedev/starlight-n0ct/components/docs/DocGrid.astro';
import FileTree from '@n0ctanedev/starlight-n0ct/components/docs/FileTree.astro';
import Kbd from '@n0ctanedev/starlight-n0ct/components/docs/Kbd.astro';
import Step from '@n0ctanedev/starlight-n0ct/components/docs/Step.astro';
import Steps from '@n0ctanedev/starlight-n0ct/components/docs/Steps.astro';
~~~

These are presentation components, not replacements for Starlight's semantic page structure. Native Starlight components such as Card, CardGrid, Tabs, Steps, and FileTree remain available and receive N0ctane styling where applicable.

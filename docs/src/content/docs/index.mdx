## Make the theme yours

Tune a palette in the [live theme playground](/reference/theme/#live-theme-playground), preview real components, and copy the generated configuration into your project. Colors are resolved into semantic roles, so custom styling can follow the active theme without hard-coded values.

<Callout tone="tip" title="One config, your setup">
  Enable only the integrations you need. Each built-in integration can be configured independently or disabled entirely.
</Callout>

## Start with a complete project

Use the installer to scaffold a documentation site or a Blog + Documentation publication.

~~~sh
# Documentation site
npx @n0ctanedev/starlight-n0ct init my-docs

# Blog and documentation
npx @n0ctanedev/starlight-n0ct init my-publication --template blog
~~~

The interactive installer lets you choose a template and toggle integrations with the keyboard. You can also run it non-interactively with `--yes`.

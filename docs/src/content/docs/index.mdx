## The visual language

N0ctane takes its palette from the N0ctOS identity: deep violet-black, electric purple, magenta and cyan. Dark mode leans purple; light mode leans blue.

Glow is used as an interaction cue, not painted onto every surface. Text and code remain readable, and animation follows `prefers-reduced-motion`.

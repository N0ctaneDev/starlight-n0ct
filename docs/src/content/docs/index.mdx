## A theme system, not just a color swap

Choose a named palette and edit its dark and light appearances independently. Every palette resolves into semantic roles for surfaces, text, borders, focus states, status colors, code syntax, gradients, and shadows.

## Two templates. One config.

Start with a focused documentation site, or choose the Blog + Documentation template for posts, tags, authors, and reading metrics.

~~~sh
# Documentation site
npx @n0ctanedev/starlight-n0ct init my-docs

# Blog and docs site
npx @n0ctanedev/starlight-n0ct init my-publication --template blog
~~~

The installer can also scaffold without installing packages, use your existing package manager, and run non-interactively with --yes.

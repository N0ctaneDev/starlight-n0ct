---
title: Integrations
description: Configure the ten integrations bundled with N0ctane.
---

All bundled integrations can be enabled with an empty object or configured with native upstream options. Set an entry to false to disable it.

~~~js
integrations: {
  basePath: {},
  announcement: { announcements: [{ content: 'Welcome to the docs!' }] },
  kbd: {},
  llmsTxt: {},
  scrollToTop: { smoothScroll: true },
  llmActions: {},
  sidebarSwipe: {},
  linksValidator: {},
  blog: {
    navigation: 'header-end',
    metrics: { readingTime: true, words: 'rounded' },
  },
  imageZoom: {},
},
~~~

| N0ct key | Package | Role |
|---|---|---|
| basePath | starlight-base-path | Prefixes root-relative content links with Astro's base |
| announcement | starlight-announcement | Announcement banners with optional scheduling and dismissal |
| kbd | starlight-kbd | Keyboard-shortcut notation |
| llmsTxt | starlight-llms-txt | LLM-friendly documentation index |
| scrollToTop | starlight-scroll-to-top | Scroll-to-top control |
| llmActions | starlight-llm-actions | Copy/view Markdown and open pages in LLM tools |
| sidebarSwipe | starlight-sidebar-swipe | Touch-swipe navigation on mobile |
| linksValidator | starlight-links-validator | Build-time internal link validation |
| blog | starlight-blog | Posts, tags, RSS, authors, and reading metrics |
| imageZoom | starlight-image-zoom | Accessible image zoom |

## Active in the demo

The demo site enables all ten integrations. You can see the announcement banner at the top of the page, use the keyboard shortcut notation in the [showcase](/showcase/), read the [blog](/blog/), open images in the zoom viewer, and switch between the current and archived docs from the version selector. The global keyboard picker and blog header link are disabled so they do not compete with the existing N0ctane ThemeSelect; blog access is provided in the footer.

The mobile sidebar supports touch gestures. The scroll-to-top button appears after scrolling. Page actions include the LLM Actions menu, and the LLM-friendly documentation index is generated by the llmsTxt integration. Base-path link handling is enabled for the GitHub Pages deployment, and linksValidator checks internal links during the docs build.

## Keyboard shortcut defaults

N0ctane supplies macOS, Windows, and Linux keyboard types when kbd.types is omitted. Linux is the fallback type. Provide your own types array to replace these presets:

~~~js
integrations: {
  kbd: {
    types: [
      { id: 'mac', label: 'macOS', detector: 'apple' },
      { id: 'windows', label: 'Windows', detector: 'windows' },
      { id: 'linux', label: 'Linux', detector: 'linux', default: true },
    ],
  },
},
~~~

## Blog setup

Blog content uses the Starlight docs collection with blogSchema merged into docsSchema. Configure global authors and metrics under integrations.blog. The [demo posts](/blog/) show author metadata, tags, excerpts, and featured posts.

## LLM index ownership

The dedicated llmsTxt integration is enabled by default. starlight-llm-actions can also generate an LLM index. N0ctane avoids duplicate output by letting the dedicated plugin own it unless you set llmsTxt: false.

## Upstream configuration

N0ctane passes option objects to the upstream plugin factories. See the upstream documentation for [Announcement](https://frostybee.github.io/starlight-announcement/), [Keyboard](https://github.com/HiDeoo/starlight-kbd), [LLMs.txt](https://github.com/delucis/starlight-llms-txt), [Scroll to top](https://github.com/frostybee/starlight-scroll-to-top), [LLM Actions](https://holdenhewett.github.io/starlight-llm-actions/), [Sidebar swipe](https://github.com/trueberryless-org/starlight-sidebar-swipe), [Links validator](https://github.com/HiDeoo/starlight-links-validator), [Blog](https://github.com/HiDeoo/starlight-blog), and [Image zoom](https://github.com/HiDeoo/starlight-image-zoom) for their full option lists.

---
title: Integrations
description: Enable and configure the Starlight plugins bundled with N0ctane.
---

N0ctane bundles ten optional integrations. Enable an integration with an options object, disable it with false, or pass the upstream package's native options. Documentation versioning uses the separate root-level versioning option.

## Available integrations

| Key | What it does | Upstream package |
|---|---|---|
| basePath | Prefixes root-relative links using Astro's configured base path | starlight-base-path |
| announcement | Adds an announcement banner | starlight-announcement |
| kbd | Adds keyboard shortcut notation and keycap support | starlight-kbd |
| llmsTxt | Generates LLM-friendly documentation index files | starlight-llms-txt |
| scrollToTop | Adds a floating scroll-to-top control | starlight-scroll-to-top |
| llmActions | Adds copy/view Markdown, PDF, and open-in-LLM page actions | starlight-llm-actions |
| sidebarSwipe | Adds touch-swipe sidebar navigation | starlight-sidebar-swipe |
| linksValidator | Checks internal links during builds | starlight-links-validator |
| blog | Adds posts, tags, author pages, RSS, and reading metrics | starlight-blog |
| imageZoom | Adds an accessible image zoom viewer | starlight-image-zoom |

## Example configuration

~~~js
integrations: {
  basePath: {},
  announcement: { announcements: [{ content: 'Welcome to the documentation!' }] },
  kbd: {},
  llmsTxt: {},
  scrollToTop: { smoothScroll: true },
  llmActions: {},
  sidebarSwipe: {},
  linksValidator: {},
  blog: {
    navigation: 'header-end',
    metrics: { readingTime: true, words: 'rounded' },
  },
  imageZoom: {},
},
~~~

The option objects are forwarded to each upstream package, except where N0ctane supplies safe defaults or composes a component to avoid conflicts.

## LLM indexes

The dedicated llmsTxt integration owns the site-level indexes by default. If you want starlight-llm-actions to generate them instead, disable the dedicated plugin:

~~~js
integrations: {
  llmsTxt: false,
  llmActions: {},
},
~~~

Enabling both generators for the same routes is rejected.

## Keyboard defaults

When kbd is enabled and no custom types are supplied, N0ctane adds macOS, Windows, and Linux presets. Linux is the fallback. A global keyboard layout picker appears only when you explicitly enable globalPicker in the kbd options.

## Blog schema

The Blog integration reads metadata from the docs content collection. Merge blogSchema into docsSchema in your content configuration. The generated blog template already does this. The docs starter includes the schema extension so Blog can be enabled later.

## Sidebar and versioning interactions

List/dropdown sidebar topics and Blog route generation can share the same site. Blog-generated routes should remain excluded from topic routing where needed. Documentation versioning is configured separately and should generally exclude blog routes so posts keep stable URLs.

---
title: Project installer
description: Scaffold a docs site or blog publication with keyboard-driven setup.
---

The installer creates a ready-to-run Astro Starlight project. It copies a selected template, writes the project-specific config and package.json, creates the deployment environment file, and can install dependencies automatically.

## Run the installer

~~~sh
npx @n0ctanedev/starlight-n0ct init my-docs
~~~

It gathers the project title, description, public URL, base path, and sidebar presentation. It then prompts for a template and optional integrations.

## Template picker

Use the arrow keys and Enter to choose:

| Template | Includes |
|---|---|
| Documentation starter | Starter homepage, docs sections, guides, reference structure, and the theme defaults |
| Blog + documentation | Docs plus Blog navigation, author configuration, tags, sample posts, and the Blog schema |

The blog template enables the blog integration. You can still change its route, authors, metrics, and navigation in n0ct.config.mjs.

## Integration picker

The optional integration selector is a multi-select list:

| Key | Action |
|---|---|
| Up / Down | Move the active row |
| Space | Toggle the selected integration |
| Enter | Confirm the selected set |
| A | Select all integrations |
| N | Clear all integrations |
| Ctrl+C | Cancel setup |

Each integration row includes a short description. A recommended set is selected by default. Base path rewriting is also preselected when the public site uses a subpath such as /docs; leave it enabled unless you intentionally manage those links yourself. Every unselected integration is written as false in the generated config.

## Command options

~~~sh
# Skip all prompts and use recommended defaults
npx @n0ctanedev/starlight-n0ct init my-docs --yes

# Select a template without opening the template selector
npx @n0ctanedev/starlight-n0ct init my-site --template blog

# Generate files without installing dependencies
npx @n0ctanedev/starlight-n0ct init my-docs --no-install

# Choose the package manager
npx @n0ctanedev/starlight-n0ct init my-docs --pm pnpm

# Show options
npx @n0ctanedev/starlight-n0ct --help
~~~

Available package managers are npm, pnpm, yarn, and bun. Without --pm, the installer checks the current npm user agent and nearby lockfiles.

## Generated files

The selected template contains:

- Astro and Starlight configuration.
- n0ct.config.mjs and a site favicon.
- Starlight docs and i18n collections.
- Blog and Sidebar Topics schema extensions, ready for their respective integrations.
- The versions collection loader, ready to enable when needed.
- Example docs content and a custom 404 page.
- A GitHub Pages workflow and deployment notes.

The installer rewrites the project title, site URL, base path, sidebar, integrations, and package metadata for the new project.

## After generation

~~~sh
cd my-docs
npm run dev
~~~

Read DEPLOY.md before publishing, especially when deploying below a repository subpath.

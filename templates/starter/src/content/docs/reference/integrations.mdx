---
title: Built-in integrations
description: Optional features included with the N0ctane theme.
---

The theme bundles its integrations, so the starter project does not need to install each plugin separately.

| Config key | Feature |
|---|---|
| `basePath` | Root-relative links respect Astro's configured base path |
| `announcement` | Announcement banners |
| `kbd` | Keyboard shortcuts and layout support |
| `llmsTxt` | LLM-friendly documentation indexes |
| `scrollToTop` | Scroll-to-top control |
| `llmActions` | LLM actions and related tooling |
| `sidebarSwipe` | Mobile sidebar swipe gestures |
| `linksValidator` | Build-time internal link validation |
| `blog` | Blog support and frontmatter |
| `imageZoom` | Image zoom |

Set an integration to `false` in `n0ct.config.mjs` to disable it.

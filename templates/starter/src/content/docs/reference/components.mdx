## Fenced code blocks

Only standard Markdown fences are needed. Expressive Code provides syntax highlighting and a simple title row when requested.

~~~bash title="Build the documentation"
npm run build
~~~

## Code tabs

Use :::code-tabs with a shared sync key to persist the selected language across blocks.

:::code-tabs{sync="starter-example"}

~~~js label="JavaScript"
const greeting = 'Hello, N0ctane';
console.log(greeting);
~~~

~~~ts label="TypeScript"
const greeting: string = 'Hello, N0ctane';
console.log(greeting);
~~~

:::

## Diff highlighting

Deleted rows are red and inserted rows are green.

~~~diff lang="ts"
export default {
  title: 'N0ctOS',
- theme: { glow: 'subtle' },
+ theme: { glow: 'balanced' },
};
~~~

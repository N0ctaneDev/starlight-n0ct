---
title: Getting started
description: Start the local development server and publish your first documentation page.
---

Your documentation project has been scaffolded. When you used the installer's default flow, its dependencies are already installed. If you used `--no-install`, run `npm install` first.

## Start the development server

~~~sh
npm run dev
~~~

Open the local URL printed by Astro. Edit the pages in `src/content/docs/`; the browser refreshes as you save.

## Build the production site

~~~sh
npm run build
npm run preview
~~~

Astro writes the static site to `dist/`. Deploy that directory to your static hosting provider.

## Add a page

Create a Markdown or MDX file under `src/content/docs/`, then place it in a topic directory such as `guides/` or `reference/`. The sidebar generates navigation from those folders.

## Blog option

This template is documentation-only. Blog is disabled by default; enable `integrations.blog` in `n0ct.config.mjs` or create a new project with the Blog + Documentation template when you want example posts and author profiles.

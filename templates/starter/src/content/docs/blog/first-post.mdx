This is a real blog post powered by **Starlight Blog**. It lives alongside your documentation in `src/content/docs/blog/`.

## What belongs here?

Use the blog for release announcements, engineering notes, tutorials, and project updates. The plugin builds the post list, tag pages, author pages, and RSS feed for you.

## Make it yours

Edit the frontmatter to set the publication date, authors, excerpt, tags, and optional cover image. Then replace this content with your first update.

The starter is intentionally small. Start by updating the title and description in `n0ct.config.mjs`, then replace the example pages with your own content.

## Suggested first steps

1. Set your public URL and base path in `.env`.
2. Replace the homepage copy and sidebar topics.
3. Add your project-specific pages under `src/content/docs/`.
4. Run `npm run build` before deploying.
